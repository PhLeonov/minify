# Minify

Теперь есть и **PWA для iPhone/Android**: [сборка, бесплатный хостинг и установка](PWA.md). Готовый архив для размещения — `build/minify-pwa.zip`. Desktop-версия остаётся отдельной и использует то же ядро сжатия.

Desktop-приложение на Go для уменьшения размера файлов фотографий. Интерфейс на русском, обработка локальная. Первая сборка предназначена для Windows 10/11 x64 с WebView2 Runtime.

## Запуск

Откройте `build/bin/Minify.exe`, выберите фотографии, качество и нажмите «Сжать фотографии». По умолчанию файлы сохраняются в подпапку `Minify` рядом с каждым оригиналом. Можно выбрать общую папку результатов.

## Возможности

- Пакетная обработка JPEG и PNG с миниатюрами и показом экономии.
- Качество JPEG от 10 до 100, три готовых режима.
- Оптимизация PNG без изменения пикселей при исходном разрешении; прозрачность сохраняется.
- Дополнительное преобразование PNG в JPEG (прозрачность заменяется белым фоном).
- Исходное разрешение по умолчанию; опциональное уменьшение длинной стороны без увеличения маленьких фото.
- Учёт поворота EXIF. Метаданные удаляются при перекодировании.
- Оригиналы и существующие файлы не перезаписываются; повторные имена получают числовой суффикс.
- Если результат не меньше исходника, сохраняется точная копия исходника с исходным расширением. В этом случае выбранное преобразование/уменьшение не применяется, метаданные сохраняются, интерфейс показывает «Уже компактно».
- Прогресс, отдельные ошибки файлов и отмена между этапами обработки. Текущий этап декодирования/кодирования не прерывается мгновенно.

## Разработка и сборка

Нужен Go 1.25+ и WebView2 Runtime. Node.js для сборки не нужен: HTML/CSS/JS встроены в исполняемый файл.

```powershell
go mod download
go test ./...
go vet ./...
go run github.com/wailsapp/wails/v2/cmd/wails@v2.15.0 build
```

Результат: `build/bin/Minify.exe`. Для разработки можно использовать `go run github.com/wailsapp/wails/v2/cmd/wails@v2.15.0 dev`.

Для просмотра только интерфейса в браузере: `node scripts/preview.cjs`, затем `http://127.0.0.1:4178`. Выбор файлов и обработка работают только в desktop-приложении.

## Ограничения первой версии

JPEG-сжатие с потерями: меньший файл может содержать меньше деталей. PNG часто уже хорошо сжат; для заметной экономии можно выбрать JPEG. Размер экономии зависит от фотографии.

Поддерживаются статические JPEG/PNG до 60 мегапикселей и 256 МБ на файл. WebP, HEIC, AVIF и анимированный PNG пока не поддерживаются. Не предназначено для архивного хранения и профессиональной цветопробы: ICC-профили и прочие метаданные не переносятся, при изменении размера/конвертации 16-битного PNG разрядность может снизиться.

Основа интерфейса — [Wails v2](https://wails.io/docs/gettingstarted/installation/), обработка — стандартные кодеки Go и `github.com/disintegration/imaging`.
